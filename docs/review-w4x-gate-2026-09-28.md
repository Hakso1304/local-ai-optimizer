# RELEASE RECORD — REQUIRED FOR EVERY ITEM

Fable releases one named invocation, owned by one worker, against one recorded manifest and native argv array. A retry, resume, changed flag, changed model/backend, or new output name needs an updated gate and explicit release. A whole A/B batch may be one invocation only if all its cases are enumerated in the released plan.

| Check | Exact evidence required before launch |
|---|---|
| Fix/test baseline | Released 40-hex HEAD contains the accepted W1–W4 fixes and U2/U3 fixes; W re-check names that HEAD or proves unchanged relevant files. Record scoped fake-test command, timestamp, exit code and counts for ownership/reconciliation, ambiguous owner queries, manifest/command binding, anchored session ID and checkpoint failures. No ordinary red tests accepted as expected failures. |
| Source checkout | Record checkout HEAD and clean `git status --porcelain` from the checkout used to prepare the archive. If the shared checkout has concurrent work, prepare from an isolated clean checkout of the pinned commit. Do not claim a shared dirty tree is clean. No dependency installation or source edits after the gate. |
| Extracted source | Record archive absolute path, ZIP SHA256, extraction root, HEAD.txt, and tracked src/scripts content-manifest SHA256 tied to that commit. Verification must compare the extracted files and expected file set with the commit/archive baseline, detecting changed, missing and unexpected executable source. Include imported JSON/assets, package metadata and executable configuration outside those directories where used. A newly computed manifest over already modified extracted files is not a baseline. |
| Dependencies | Record actual Node path/hash/version, tsx entry path/hash, package-lock and installed lockfile hashes, node_modules junction target, launcher/runner/exporter or standalone wrapper hashes. **Accepted limitation: remaining node_modules contents are pinned by lockfiles only, not individually authenticated.** Record this limitation in the gate and final evidence; freeze the junction/install for the lease. |
| Runtime/model binding | Record each resolved runtime executable path, build and SHA256; exact DLL filenames/hashes for each runtime directory; all selected GGUF real paths, byte sizes and SHA256. Prove the effective parsed argv resolves to exactly these files, including backend and model filtering. Reject duplicate/conflicting selector flags and unexpected extra selected models. Record vendor/model junction targets. |
| Native command | Record working directory, executable, full argv array, parsed JSON pins/gen configs, backend/device, ladder, reps/warmup and output paths. Demonstrate shell:false/windowsHide:true at process spawns and the fake native-argv roundtrip for any external launcher. Hash an external launcher/config as part of the release. |
| Ownership | Timestamped process inventory shows zero competing llama-server, typeperf, run-session and ab-spill processes, plus no other measurement owner. Previous lease has verified teardown; at least 60 seconds idle have elapsed. No full-suite/Electron startup, runtime scan, live telemetry test or unrelated hardware probe may overlap. Ambiguous identity/enumeration is HOLD, never permission to kill a foreign PID. |
| Environment | Timestamped Process/User/Machine checks show no key equal to GGML_CUDA_ENABLE_UNIFIED_MEMORY in any casing, even with an empty value. All child envs strip that key case-insensitively. |
| RAM/device | Fresh available RAM >=12 GiB; expected RX 9070 XT identity, driver and adapter mapping recorded; dedicated VRAM at the expected idle baseline (historically about 1.1–1.2 GiB), with the actual reading and timestamp. Unknown reading or unexplained contention is HOLD. A different baseline requires explicit reassessment, not substitution with zero. |
| Bounds/reaping | Explicit request cap <=300000 ms and live RAM floor >=4 GiB; watchdog covers preflight, load, warmup, reps, quality/proof, retries, switches and cleanup. OS/health probes have finite deadlines. Accepted W1 tests prove uncaptured/late descendants prevent successful cleanup, PID reuse does not authorize foreign kills, and overlapping stops share teardown. |
| Artifacts | Single-use label; manifest/config/log/export/standalone output destinations are absent and created exclusively. Dump reservation/checkpoint/.previous policy is established before work. Record enough disk space for logs/checkpoints/exports. Preserve failed/partial artifacts; never reuse their names or delete them to enable a retry. |
| Last check | Source/dependency/runtime/model/argv verification runs immediately before spawn, under supervision. Recheck process/env/RAM/device state if gate preparation took time. An earlier preflight is not proof of current lane ownership. |

# COMPLETION GATE BEFORE THE NEXT RELEASE

- Record child identities and teardown result, final zero owned servers/samplers/harnesses, minimum RAM, abort/timeout/error status, and start/end times. An unknown/surviving child or changed identity keeps HOLD; do not kill another worker's process.
- Reverify source/dependency/runtime/model fingerprints and command binding after teardown. A mismatch quarantines results even if measurements completed. Hash and preserve output plus partial/checkpoint artifacts, including failed attempts.
- For sessions, anchored ID must match exported session/request/provenance; verify expected item/sample/seed coverage, per-row proof and accepted sampling before a generation comparison. Export remains read-only against DB and no-clobber on disk. Standalone outputs retain both streams, host/device buffer separation and unavailable fields as null.
- Release claims only within measured scope: a clean software gate is not proof of buffer origin, capacity, reasoning token split or a quality winner. Preserve existing historical caveats and pinned-config labels.
- After verified teardown and >=60 seconds idle, prepare a new fresh preflight for the next named item. **Missing or ambiguous mandatory evidence means HOLD; a completed checklist is evidence for Fable's release decision, not self-authorization.**
