# REMAINING FINDINGS — RANKED
**T1 HIGH — final enumeration sees an unknown survivor but cleanup ignores it.** src/core/runtimes/llamacpp/index.ts:535 discards `await scan()` and checks only the previously captured children map. Executed fake tree: initial scan empty; parent kill succeeds; second scan returns a child born after the first scan which remains alive. Result: unload resolves, only root808 killed, ownedRootPid cleared, child909 untouched. This violates “uncaptured descendants → fatal” and permits another model/server with a survivor. Fix: reconcile every verification scan; any newly observed potential owned descendant must be identity-verified and reaped or cause ServerStuckError with ownership retained. Never treat a successful query as proof its returned tree is empty.

**T2 HIGH — individual child identity does not prove the parent's generation/ancestry.** Default descendants traversal (:103–110) tracks numeric parent PIDs; unload(:510–514) adopts all enumerated descendants while root is live. Executed fake seam models intermediate parent909 captured before reuse, then foreign child910 enumerated under reused909. inspect(909) returns the new creation time, so old909 is spared; inspect(910) matches its own record and killVerified(910) is invoked. Child identity is valid but ownership is false. Fix: bind every ancestry edge to its parent's creation identity, invalidate the subtree if a parent changes, and revalidate the chain before adopting/killing; an owned Job Object/retained handles avoids numeric ancestry races. Same-name matching must never substitute for this chain.

**T3 MED — direct interpretation does not share the replay tool's coherent-origin validator.** src/core/interpret/verdicts.ts:169–173 checks array presence/truthiness but not ISO timestamp, lineage hash syntax, or runtime-mode null-time/empty-lineage constraints. Executed public verdicts with an otherwise valid low row and `{mode:'runtime', origin:{generationPromptHashPresent:true, firstReplayAt:'not-an-iso-time', lineage:['not-a-hash']}}` (matching original=true/status=original): comparable=true. Switching mode to live-template-replay also passes. Replay tool rejects these records, so ordinary tool output is protected; imported/migrated rows bypassing it are not. Fix: use one coherent-origin validator at replay and interpretation/storage boundaries; missing artifact lineage context must not become implicitly verified.
