## D01 — HIGH — Shared-spill abort is not unconditional

**Claims:** `docs/ARCHITECTURE.md:132,168`, `docs/BENCHMARK.md:52`, `docs/LIMITATIONS.md:79` say per-PID shared memory above 2 GiB aborts the running request.
**Contradiction:** `src/core/benchmark/session.ts:445` explicitly excludes `expectDegraded` candidates and subtracts host-pinned memory and the baseline; `:268` stops a heavy ladder only after the step completes. `:583` explicitly omits a spill guard for quality. The later explanation at `docs/BENCHMARK.md:211` already contradicts the earlier blanket rule.
**Scenario:** a heavy run crosses 2 GiB adjusted spill and continues inference; a user expecting the advertised immediate safety abort waits until the step ends (or another guard fires).
**Fix:** describe raw versus adjusted spill, the heavy-mode post-step stop, and the quality-phase exception in every safety summary.

## D02 — HIGH — Claimed conservative KV bound is not an OOM guarantee

**Claims:** `docs/LIMITATIONS.md:64` says the unknown-architecture upper bound is “conservative, never OOM from an under-estimate”; `:65` says 1 GiB covers recurrent state; `docs/BENCHMARK.md:243` says the fallback is “never 0.”
**Contradiction:** `src/core/benchmark/candidates.ts:75` returns `bytes:0, unknown:true` for missing heads/dimensions; `:80` omits recurrent-layer state; `:122` combines heuristic weight/compute/KV estimates. No proof or calibration spans arbitrary recurrent architectures. The real heavy-run account (`docs/calibration-heavy-2026-09-27.md:5,35`) records a host-memory failure despite estimates/guards.
**Scenario:** metadata lacks KV head information, or a hybrid model has more recurrent state than the assumed residual; a generated probe can allocate substantially more than estimated.
**Fix:** document a conditional KV-only estimate, explicitly state missing-metadata behavior, and remove the universal OOM/residual-margin guarantee.

## D03 — HIGH — The documented minimum decode speed can be bypassed intentionally

## T12 — MED — Real-clock/process timing can flake under CI load
